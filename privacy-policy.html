นโยบายความเป็นส่วนตัว (Privacy Policy)

วันที่มีผลบังคับใช้: 24 มิถุนายน 2569

แอปพลิเคชัน UP Bus Transit พัฒนาและดูแลโดย ศูนย์สิ่งแวดล้อมและการจัดการที่ยั่งยืน มหาวิทยาลัยพะเยา (Center for Environmental and Sustainable Management, University of Phayao) นโยบายนี้อธิบายข้อมูลที่เราเก็บรวบรวม วัตถุประสงค์การใช้งาน และสิทธิ์ของท่าน

1. ข้อมูลที่เราเก็บรวบรวม

  • ข้อมูลตำแหน่ง (Location Data) — แอปฯ ใช้ข้อมูล GPS ของรถโดยสารจากระบบ GPS ของมหาวิทยาลัย เพื่อแสดงตำแหน่งรถแบบ Real-time บนแผนที่ แอปฯ ไม่เก็บข้อมูลตำแหน่งของผู้โดยสาร
  • LINE User ID — ใช้เพื่อยืนยันตัวตนของพนักงานขับรถผ่าน LINE LIFF โดยไม่มีการเก็บรหัสผ่านหรือข้อมูล LINE ส่วนตัวอื่น
  • ข้อมูลพนักงานขับรถ — ชื่อ-นามสกุล และ LINE User ID ที่ลงทะเบียนผ่านระบบ
  • ข้อมูลการร้องเรียน — หัวข้อ รายละเอียด และรูปภาพที่ผู้ใช้ส่งผ่านระบบร้องเรียน
  • ข้อมูลการประเมิน — คะแนนความพึงพอใจที่ผู้ใช้ให้ไว้ (ไม่ระบุตัวตน)

2. วัตถุประสงค์การใช้ข้อมูล

  • แสดงตำแหน่งรถโดยสารแบบ Real-time บนแผนที่ภายในมหาวิทยาลัย
  • จัดการการมอบหมายพนักงานขับรถและสถานะรถโดยสาร
  • รับและจัดการเรื่องร้องเรียนเกี่ยวกับบริการ
  • วิเคราะห์และปรับปรุงคุณภาพการให้บริการขนส่งภายในมหาวิทยาลัย

3. การจัดเก็บและความปลอดภัยของข้อมูล

ข้อมูลถูกจัดเก็บในฐานข้อมูล MySQL บนเซิร์ฟเวอร์ของมหาวิทยาลัยพะเยา ข้อมูลตำแหน่ง GPS ของรถโดยสารถูกจัดเก็บเฉพาะในหน่วยความจำชั่วคราว (RAM) และไม่มีการบันทึกลงฐานข้อมูลถาวร เราใช้มาตรการรักษาความปลอดภัยตามมาตรฐานที่เหมาะสม เพื่อป้องกันการเข้าถึงข้อมูลโดยไม่ได้รับอนุญาต

4. การเปิดเผยข้อมูลแก่บุคคลที่สาม

เราไม่ขาย แลกเปลี่ยน หรือถ่ายโอนข้อมูลส่วนบุคคลของท่านให้แก่บุคคลภายนอก ยกเว้นในกรณีที่จำเป็นตามกฎหมายหรือคำสั่งของหน่วยงานที่มีอำนาจ

5. สิทธิ์ของผู้ใช้

  • ขอดู แก้ไข หรือลบข้อมูลส่วนบุคคลของท่าน
  • ขอถอนความยินยอมในการเก็บข้อมูลได้ทุกเมื่อ

โปรดติดต่อเราผ่านช่องทางด้านล่างเพื่อใช้สิทธิ์ดังกล่าว

6. บริการของบุคคลที่สาม

แอปฯ ใช้บริการต่อไปนี้:

  • LINE LIFF — สำหรับยืนยันตัวตนพนักงานขับรถ (นโยบายความเป็นส่วนตัวของ LINE)
  • Leaflet.js / OpenStreetMap — สำหรับแสดงแผนที่ (ไม่เก็บข้อมูลผู้ใช้)

7. การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายนี้เป็นครั้งคราว การเปลี่ยนแปลงจะมีผลทันทีเมื่อเผยแพร่บนหน้านี้ ขอแนะนำให้ตรวจสอบนโยบายนี้เป็นระยะ

8. ช่องทางติดต่อ

ศูนย์สิ่งแวดล้อมและการจัดการที่ยั่งยืน
